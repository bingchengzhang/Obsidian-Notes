# 累次极限与二重极限:几何、结构与关系

> 本文为纠正后的完整版 v2,剔除了讨论过程中使用过的不精确比喻("塌缩顺序""串行 vs 并行""任意顺序""同速率趋近"等),补充了 Moore-Osgood 的精确陈述、齐次性分析、一致收敛的 $\delta$-族视角,以及"一致性 = 独立性"的结构化理解。

------

## 一、两类极限的精确定义

### 1.1 二重极限

$$ \lim_{(x, y) \to (x_0, y_0)} f(x, y) = A $$

$\varepsilon$-$\delta$ 定义:

$$ \forall \varepsilon > 0,\ \exists \delta > 0,\ \forall (x, y):\ 0 < \sqrt{(x-x_0)^2 + (y-y_0)^2} < \delta \Rightarrow |f(x,y) - A| < \varepsilon $$

**结构**:一次二维极限操作。控制的是 $(x_0, y_0)$ 去心圆盘邻域内 $f$ 的整体行为。

**注**:定义里严格是圆盘条件。实际计算常用等价的方形条件 $|x - x_0| < \delta$ 且 $|y - y_0| < \delta$——两者互相包含,极限定义等价,方形更便于代数操作。

### 1.2 累次极限

$$ \lim_{x \to x_0} \lim_{y \to y_0} f(x, y) \quad \text{与} \quad \lim_{y \to y_0} \lim_{x \to x_0} f(x, y) $$

**结构**:两次嵌套的一元极限操作。以 $\lim_x \lim_y$ 为例:

- **内层**:对每个固定的 $x$(可远离 $x_0$),建立一元函数 $\varphi(x) := \lim_{y \to y_0} f(x, y)$。要求这个一元极限对每个 $x$ 都存在。
- **外层**:对 $\varphi$ 再做一元极限 $\lim_{x \to x_0} \varphi(x)$。

**"内外层都要存在"的必然性**:内层不存在则 $\varphi$ 在某些 $x$ 上无定义,外层的被极限对象缺失;外层是对 $\varphi$ 自身的极限,$\varphi$ 必须在 $x \to x_0$ 时收敛才算累次极限存在。

### 1.3 结构对比

|          | 极限操作               | 控制对象                              |
| -------- | ---------------------- | ------------------------------------- |
| 二重极限 | **一次**二维极限       | $(x,y)$ 落在小圆盘内时 $f$ 的整体行为 |
| 累次极限 | **两次嵌套**的一元极限 | 每次只动一个变量的切片函数            |

两者是**结构上根本不同**的极限定义,不是"塌缩顺序"的差别。

## 二、几何视角

### 2.1 定义域层与函数图像层

- **定义域层**:$(x_0, y_0)$ 的邻域是 $\mathbb{R}^2$ 中的开圆盘 $U$——一个二维平面区域,只含位置信息。
- **函数图像层**:把 $f$ 的信息附加上去,$U$ 上每个点被抬到高度 $z = f(x, y)$,圆盘上方"长出"一块二维曲面片,浮在 $\mathbb{R}^3$ 中。

### 2.2 二重极限的几何

**允许所有路径**:$(x, y)$ 沿任何连续参数化曲线 $\gamma(t) = (x(t), y(t))$ 趋近 $(x_0, y_0)$。$x(t)$ 和 $y(t)$ 在**同一个参数 $t$ 下**同步变化。"任意路径"包括直线、抛物线、螺旋线、$y = x\sin\frac{1}{x}$ 型扭曲曲线等——**所有**连续参数化方式。

**几何图像**:当 $(x, y)$ 覆盖整个小圆盘 $U_\delta$ 时,对应的曲面片整体趋向水平面 $z = A$。两个层次的塌缩同步发生:

- 定义域层:圆盘 $U_\delta$ 随 $\delta \to 0$ 塌缩成点 $(x_0, y_0)$。
- 函数图像层:圆盘上方的曲面片整体塌向 $\mathbb{R}^3$ 中的点 $(x_0, y_0, A)$。

### 2.3 累次极限的几何

**不是"折线路径"的极限,而是两次一元极限的嵌套**。以 $\lim_x \lim_y$ 为例:

- **内层操作**:对每个固定 $x$,在 $\mathbb{R}^3$ 中沿竖直切片 ${x} \times \mathbb{R}$ 看 $y \to y_0$ 的极限,得到一个数 $\varphi(x)$。几何上相当于把曲面片沿 $y$ 方向"压成"一条曲线 $z = \varphi(x)$(前提是这一步每条竖切片都成功)。
- **外层操作**:在这条 $\varphi(x)$ 曲线上做 $x \to x_0$ 的一元极限,得到最终值。

两步**降维**:曲面(2 维) → 曲线(1 维) → 点(0 维)。

### 2.4 关键区分:切片 vs 联合逼近

- 二重极限看的是**联合逼近**——$x$ 和 $y$ 同时向 $(x_0, y_0)$ 靠近时的整体行为。
- 累次极限的内层看的是**固定切片上的一维行为**——固定 $x = c$(可能远离 $x_0$),切片函数 $y \mapsto f(c, y)$ 作为独立一元函数的极限。

**关键事实**:固定 $x = c \neq x_0$ 时,这条竖切片**大部分位于小圆盘 $U_\delta$ 之外**(因为 $|c - x_0|$ 是个不随 $\delta$ 变化的正常数)。二重极限的 $\varepsilon$-$\delta$ 控制**伸不到**这条切片——切片的行为是二重极限之外的独立信息。

## 三、两类极限的相互关系

### 3.1 核心引理

**若二重极限存在 $= A$,且某个累次极限也存在,则该累次极限 $= A$。**

**证明要点**:二重极限的 $\varepsilon$-$\delta$ 控制覆盖到累次极限的**外层步骤**。固定 $x$ 满足 $0 < |x - x_0| < \delta/2$,对任意 $|y - y_0|$ 足够小,$(x, y)$ 落在 $\delta$ 圆盘内,$|f(x,y) - A| < \varepsilon$。两边取 $y \to y_0$,得 $|\varphi(x) - A| \leq \varepsilon$,对所有这样的 $x$ 成立。所以 $\lim_{x \to x_0} \varphi(x) = A$。$\square$

**关键**:引理只说"若累次存在,则 $= A$",**不说"累次一定存在"**。

### 3.2 完整关系表

| 已知条件                      | 可推结论                                |
| ----------------------------- | --------------------------------------- |
| 二重存在 $= A$ 且两累次都存在 | 两累次都 $= A$,三者相等                 |
| 二重存在 $= A$ 且某累次存在   | 该累次 $= A$;另一累次存在性**不确定**   |
| 二重存在                      | 两累次是否存在**均不确定**              |
| 两累次都存在但不相等          | **二重必不存在**                        |
| 两累次都存在且相等            | 二重**可能存在,可能不存在**(需额外条件) |
| 某累次不存在                  | 对二重与另一累次都无直接结论            |

### 3.3 "两累次不等 ⇒ 二重不存在" 的证明

反证。设二重存在 $= L$。由引理,两个累次都必须 $= L$,故相等。与"两累次不等"矛盾。$\square$

**实用价值**:这是判定二重极限不存在的**最系统方法**——只需做两次机械的一元极限,不需要猜测奇怪路径。

## 四、Moore-Osgood 定理与一致收敛

### 4.1 Moore-Osgood 定理(精确版)

**设**:

- $\varphi(x) := \lim_{y \to y_0} f(x, y)$ 对每个 $x$(在 $x_0$ 去心邻域内)存在,且**该收敛关于 $x$ 一致**;
- $\lim_{x \to x_0} \varphi(x) = A$ 存在。

**则**:

$$ \lim_{(x,y) \to (x_0, y_0)} f(x, y) = A $$

**定理陈述里没有"两累次相等"这个前提**——只需要一个方向的累次存在 + 一致收敛,就能推出二重。两累次相等是推论里顺带得到的结果(由核心引理),不是条件本身。

### 4.2 一致收敛的定义

**逐点收敛**(每个 $x$ 的内层极限都存在):

$$ \forall x,\ \forall \varepsilon > 0,\ \exists \delta(x, \varepsilon) > 0,\ |y - y_0| < \delta(x, \varepsilon) \Rightarrow |f(x, y) - \varphi(x)| < \varepsilon $$

$\delta$ **可以依赖 $x$**——每个 $x$ 有专属的 $\delta$。

**一致收敛**(关于 $x$):

$$ \forall \varepsilon > 0,\ \exists \delta(\varepsilon) > 0,\ \forall x,\ |y - y_0| < \delta(\varepsilon) \Rightarrow |f(x, y) - \varphi(x)| < \varepsilon $$

$\delta$ **只依赖 $\varepsilon$,对所有 $x$ 统一**。

量词顺序从 $\forall x \exists \delta$ 变为 $\exists \delta \forall x$——这是唯一的差别,但整个收敛的"质量"根本变了。

### 4.3 $\delta$-族的几何与速率解读

**$\delta$ 反映收敛速率**:给定精度 $\varepsilon$,所需门槛 $\delta$ 越大 $=$ $y$ 不用很接近就达标 $=$ 收敛快;$\delta$ 越小 $=$ $y$ 必须极贴近才达标 $=$ 收敛慢。

把每个 $x$ 对应的 $\delta(x, \varepsilon)$ 画成一张表,**就是一族收敛速率**。一致收敛的充要条件:

$$ \inf_x \delta(x, \varepsilon) > 0 \text{ 对每个 } \varepsilon > 0 \text{ 成立} $$

**一致 $\iff$ $\delta$-族有正下界 $\iff$ 存在统一速率下界**——所有切片以差不多的速率收敛,没有谁掉队。

**非一致 $\iff$ $\delta$-族下确界 $= 0$ $\iff$ 速率退化**——存在某些 $x$ 使对应切片的收敛速率任意慢。

### 4.4 非一致收敛的图像特征:游击驼峰

经典例子 $f_n(x) = x^n$ 在 $[0, 1]$ 上。极限函数

$$ f(x) = \begin{cases} 0, & 0 \leq x < 1 \ 1, & x = 1 \end{cases} $$

**逐点收敛但非一致**——曲线族随 $n$ 增大,"膝盖"越来越贴近 $x = 1$,但高度永远 $= 1$,不肯消失。画一个 $\varepsilon$-管道围住极限函数,总有某段曲线钻出管道外。

**限制到 $[0, 0.9]$ 后变成一致收敛**——砍掉了速率退化的危险区,$\sup_x x^n = 0.9^n \to 0$,整族曲线整体被压进 $\varepsilon$-管道。

**判断一致收敛的基本动作**:问"$\sup_x |f_n(x) - f(x)|$(或 $\sup_x |f(x, y) - \varphi(x)|$)是否趋于 $0$?"趋 $0$ 则一致,不趋 $0$ 则非一致。

**非一致收敛的典型图像**:曲线族有一个"游击驼峰",位置随参数变化,高度不降。Moore-Osgood 反例 $\frac{x^2 y}{x^4 + y^2}$ 的内层收敛($y \to 0$),每条固定 $x$ 的切片都在 $y = x^2$ 处有高度 $\frac{1}{2}$ 的驼峰,驼峰位置随 $x \to 0$ 越来越贴近 $0$——完全同构于 $x^n$ 图像里的膝盖。

### 4.5 为什么一致收敛能"桥接"累次与二重

Moore-Osgood 证明骨架(三角不等式):

$$ |f(x, y) - A| \leq \underbrace{|f(x, y) - \varphi(x)|}*{<,\varepsilon/2,\text{要 } |y-y_0| < \delta_1} + \underbrace{|\varphi(x) - A|}*{<,\varepsilon/2,\text{要 } |x-x_0| < \delta_2} $$

**取 $\delta = \min(\delta_1, \delta_2)$** 作为二重圆盘的半径。

**问题**:如果 $\delta_1$ 依赖 $x$,$\min(\delta_1(x), \delta_2)$ **本身随 $x$ 退化到 $0$**——得不到一个固定的数 $\delta$。

**一致收敛的救场**:$\delta_1$ 不依赖 $x$,$\min$ 是两个固定数的最小值,等于一个固定数。二重圆盘半径 $\delta$ 固定,定理成立。

**一句话**:一致收敛把"嵌套的两层 $\delta$"合并成"单一的 $\delta$"——这就是从累次跨到二重的技术条件。

### 4.6 本质结构:一致性 = 两变量的独立性

累次和二重的根本差别:

- **累次**:$\lim_x \lim_y$ 里 $y$ **从属**于 $x$——内层先跑(依赖外层给定的 $x$),外层再跑。嵌套 $=$ 主从 $=$ 不对称。
- **二重**:$(x, y)$ 同时落在圆盘内,**地位对称、演化独立**——$\delta$ 对两者同等约束,不偏心任何一方。

一致收敛的作用:**消除 $y$ 对 $x$ 的从属关系**——$y$ 的阈值不看 $x$ 脸色,独立预设。于是 $x, y$ 真正平等,累次的嵌套结构在技术上退化为二重的并行结构。

**"一致性" 这个词的本质 = 两变量的独立化**。这是一个贯穿整个分析学的核心模式:

| 场景                      | 两个变量/指标              | 一致性要求的独立性                |
| ------------------------- | -------------------------- | --------------------------------- |
| 累次 → 二重(Moore-Osgood) | $x$ 和 $y$                 | $y$ 的阈值独立于 $x$              |
| 逐点连续 → 一致连续       | 基点 $x$ 和增量 $\Delta x$ | 增量阈值独立于基点                |
| 函数列逐点 → 一致         | 位置 $x$ 和步数 $n$        | 步数阈值独立于位置                |
| 参数积分求导              | 积分变量 $t$ 和参数 $x$    | 被积函数关于 $t$ 的收敛独立于 $x$ |
| 级数逐项求导              | 求和阶 + 求导阶            | 导函数级数一致收敛                |

每一个都是同一个结构:**两个控制参数原本相互依赖,一致性要求解绑其中一个对另一个的依赖**。一致收敛保证的不是"速率相等",而是"阈值可以与另一变量解耦"。

### 4.7 常见混淆澄清

**✗ 错误理解**:"二重极限 = $x, y$ 同速率趋近"。

**✓ 正确理解**:"二重极限 = $x, y$ 同时被同一 $\delta$ 约束"——$\delta$ 是**共同边界**,被约束的 $x, y$ 内部比例任意。$(x, y) = (10^{-10}, 10^{-3})$ 和 $(10^{-3}, 10^{-3})$ 都是同一 $\delta$ 圆盘内的合法点,速率可以差无穷多阶。"同速率"(如沿 $y = kx$)只是二重极限允许路径的一个特殊子集。

**✗ 错误理解**:"$\delta$ 是 $x, y$ 趋近极限点的速率"。

**✓ 正确理解**:$\delta$ 是**达到精度 $\varepsilon$ 所需的条件门槛**——反映极限过程(值向极限贴近)的快慢,不是自变量路径(位置向极限点贴近)的快慢。这两层速率概念不要混。

## 五、反例集

### 5.1 累次存在但不等 ⇒ 二重不存在

$$ f(x, y) = \frac{x - y}{x + y},\quad (x_0, y_0) = (0, 0) $$

- $\lim_{x \to 0}\lim_{y \to 0} f = \lim_{x \to 0} \frac{x}{x} = 1$
- $\lim_{y \to 0}\lim_{x \to 0} f = \lim_{y \to 0} \frac{-y}{y} = -1$

两累次不等,**直接判定**二重不存在。

### 5.2 累次都相等 ⇏ 二重存在(斜向路径反例)

$$ f(x, y) = \frac{xy}{x^2 + y^2},\quad (x_0, y_0) = (0, 0) $$

**累次极限**:沿 $x$ 轴或 $y$ 轴代入,$f \equiv 0$,两累次都 $= 0$。

**二重极限**:极坐标 $f = \frac{1}{2}\sin 2\theta$,只依赖方向不依赖半径。沿 $y = kx$:

$$ f(x, kx) = \frac{k}{1 + k^2} $$

$k$ 不同给出不同极限,二重不存在。

**几何本质**:$f$ 是零次齐次函数,$f(tx, ty) = f(x, y)$,曲面是从原点发散的"旋转波纹",不同方向的舌头高度不同。累次只采样坐标轴方向(恰好 $\sin 0 = \sin \pi = 0$),看不到斜向冲突。

### 5.3 累次存在相等 ⇏ 二重存在(直线族都对仍不够)

$$ f(x, y) = \frac{x^2 y}{x^4 + y^2},\quad (x_0, y_0) = (0, 0) $$

**沿任何直线 $y = kx$**:

$$ f(x, kx) = \frac{kx^3}{x^2(x^2 + k^2)} = \frac{kx}{x^2 + k^2} \to 0 $$

所有直线路径极限都是 $0$。

**沿抛物线 $y = x^2$**:

$$ f(x, x^2) = \frac{x^4}{2x^4} = \frac{1}{2} $$

恒等于 $\frac{1}{2}$,极限 $\neq 0$。二重不存在。

**Moore-Osgood 角度看**:内层 $\varphi(x) = \lim_{y \to 0} \frac{x^2 y}{x^4 + y^2} = 0$ 对每个 $x$ 存在,但收敛**非一致**——峰值 $|g_x|_{\max} = \frac{1}{2}$ 在 $y = \pm x^2$ 处,$x \to 0$ 时峰值位置贴近 $0$,高度不降(游击驼峰),$\delta(x, \varepsilon) \sim x^2 \to 0$ 没有正下界。

**教训**:分子分母**不同次齐次**时,必须试非线性路径。"径向极限(沿直线)存在"是比二重极限弱的条件。

### 5.4 二重存在 ⇏ 累次存在

$$ f(x, y) = \begin{cases} x \sin\dfrac{1}{y}, & y \neq 0 \ 0, & y = 0 \end{cases} $$

**二重极限**:$|f| \leq |x| \to 0$,**存在**,等于 $0$。

**累次 $\lim_{y \to 0}\lim_{x \to 0} f$**:内层 $\lim_{x \to 0} x \sin\frac{1}{y} = 0$,外层 $0 \to 0$,**存在**,等于 $0$。

**累次 $\lim_{x \to 0}\lim_{y \to 0} f$**:内层 $\lim_{y \to 0} x \sin\frac{1}{y}$,对 $x \neq 0$ 振荡,**不存在**。

**这个反例同时否定两个天真命题**:

1. "二重存在 $\Rightarrow$ 两累次都存在" ❌
2. "二重存在 + 一累次存在 $\Rightarrow$ 另一累次存在" ❌

**机制**:$|x|$ 是"振幅压制因子"。二重极限允许 $x$ 和 $y$ 一起趋于 $0$,$|x|$ 把振荡压到 $0$。累次内层把 $x$ 锁死在 $c \neq 0$,压制因子固定为 $|c|$,振荡暴露。

**两族切片的非对称性**:

- 横切片 $y = c$:$f(x, c) = x \sin\frac{1}{c}$ 是 $x$ 的线性函数,良好。
- 竖切片 $x = c \neq 0$:$f(c, y) = c \sin\frac{1}{y}$ 振荡,病态。

哪族切片良好 → 哪个累次存在。两族可以完全不对称。

## 六、判定方法:齐次性分析

### 6.1 齐次函数定义

$f : \mathbb{R}^2 \setminus {0} \to \mathbb{R}$ 是 **$n$ 次齐次**,若对所有 $t > 0$:

$$ f(tx, ty) = t^n f(x, y) $$

**零次齐次**($n = 0$)最关键:$f(tx, ty) = f(x, y)$,$f$ 只依赖方向。

### 6.2 零次齐次的二重极限判定

极坐标 $(x, y) = (r\cos\theta, r\sin\theta)$:

$$ f(r\cos\theta, r\sin\theta) = h(\theta) $$

$f$ 完全不依赖 $r$。

**结论**:零次齐次函数在原点的二重极限存在 $\iff$ $h(\theta) \equiv$ 常数。通常 $h$ 不是常数,故**零次齐次函数的二重极限通常不存在**。

### 6.3 齐次分式判定算法

最常见情况:$f = P/Q$ 分子分母同为多项式齐次。

1. **检查分子分母是否各自齐次**。若 $P$ 或 $Q$ 非齐次,齐次性分析失效(见 5.3 反例),必须试非线性路径。
2. **若 $P$ 是 $p$ 次齐次,$Q$ 是 $q$ 次齐次**,则 $f$ 是 $(p - q)$ 次齐次:
   - $p = q$(零次齐次):看 $h(\theta) = f(\cos\theta, \sin\theta)$ 是否常数。不是则二重不存在。
   - $p > q$(正次齐次):沿任何射线 $f \to 0$。若 $h(\theta)$ 有界,$|f| = r^{p-q}|h| \to 0$,二重存在 $= 0$。
   - $p < q$(负次齐次):沿射线 $f \to \infty$(若 $h \not\equiv 0$),二重不存在。

### 6.4 非齐次情形的曲线路径

若 $Q$ 非齐次(如 $x^4 + y^2$,$x^4$ 是 4 次、$y^2$ 是 2 次),试**让分母各项同阶的曲线**:

- 分母 $x^4 + y^2$:令 $y^2 = x^4$,即 $y = x^2$。
- 分母 $x^6 + y^2$:令 $y = x^3$。
- 一般 $x^a + y^b$:令 $y = x^{a/b}$。

沿这种曲线,分母两项被迫同阶,更容易与分子平衡,可能暴露非零极限。

### 6.5 判定流程(可操作版)

遇到原点处二重极限问题:

1. **先算两累次**。
   - 存在且不等 → 二重不存在,**结束**。
   - 至少一个不存在 → 另行处理(二重仍可能存在,如 $x\sin\frac{1}{y}$)。
   - 都存在且相等 → 进入第 2 步。
2. **检查分子分母齐次性**。
   - 都齐次 → 用 6.3 的算法。
   - 分母非齐次 → 进入第 3 步。
3. **试非线性路径**,特别是 6.4 的匹配曲线。
4. **若前面都没能判定不存在,尝试证明存在**(极坐标夹逼或 $\varepsilon$-$\delta$ 估计)。

## 七、核心理解框架

### 7.1 二重极限管什么,不管什么

**管**:联合逼近的稳定性——$(x, y)$ 同时向 $(x_0, y_0)$ 靠近时,$f$ 整体收敛。

**不管**:某条固定切片 $x = c \neq x_0$ 上,$f(c, \cdot)$ 作为一元函数的行为。这条切片大部分远离 $(x_0, y_0)$,二重极限的控制伸不到。

### 7.2 累次极限与二重极限的交汇点

**方向说明**:本节讨论的是"**二重 $\to$ 累次**"方向(核心引理 A),前提是二重已经存在,结论是累次在存在的前提下被二重钉死。反方向"**累次 $\to$ 二重**"(Moore-Osgood,定理 B)需要一致收敛作为额外条件,见第四章。两者方向不同,使用 $\delta$ 的方式也不同:

- **引理 A**:已有二重给的 $\delta$,**消费**它读出累次值——不需要一致收敛。
- **定理 B**:从累次的专属 $\delta_1(x)$-族**生产**出二重需要的单一 $\delta$——需要一致收敛保证 $\delta_1$ 可取为与 $x$ 无关。

**外层落在二重控制内的几何机制**:假设二重存在 $= A$。对任意固定 $x$(满足 $0 < |x - x_0| < \delta$),这条竖切线**靠近 $y_0$ 的那段**被二重圆盘罩住——该段上 $|f(x, y) - A| < \varepsilon$。当内层极限 $\varphi(x) = \lim_{y \to y_0} f(x, y)$ 存在时,在被罩住的段内取 $y \to y_0$,不等式两边取极限得 $|\varphi(x) - A| \leq \varepsilon$。这对所有 $|x - x_0| < \delta$ 成立,故外层 $\lim_{x \to x_0} \varphi(x) = A$。

**关键**:是**内层极限过程的终点段**(竖切片靠近 $y_0$ 的部分)落在圆盘内,让二重控制传导到 $\varphi(x)$——$\varphi$ 不是 $f$ 的值,而是切片极限值,但它的每个"输入 $x$"都被圆盘辐射到。

**内层**(固定 $x = c$,$y \to y_0$)本身是对切片的独立一维极限,和二重极限是**解耦的**——二重存在不保证这个内层极限存在(见 5.4 节 $x\sin\frac{1}{y}$ 反例)。引理 A 的精确表述是"**若**内层已成功建立,外层值被二重钉死",不是"内层必然存在"。

### 7.3 "选哪个做内层"的意义

不是"改变塌缩顺序",而是**决定看哪一族切片**:

- 内层做 $y$ → 检查竖切片族 ${x = c}$ 的一维振荡性。
- 内层做 $x$ → 检查横切片族 ${y = c}$ 的一维振荡性。

两族切片的振荡性**完全可以不对称**,这就是为什么两个累次存在性可以不同。

### 7.4 累次与二重的本质差异:主从 vs 对称

- **累次**:嵌套结构,$y$ 从属于 $x$,$y$ 的阈值 $\delta_1$ 可以依赖 $x$——这是**运行时动态依赖**。
- **二重**:并行结构,$x, y$ 地位对称,$\delta$ 作为单一固定数对所有 $(x, y)$ 生效——这是**编译时静态预设**。

一致收敛的技术功能:把"$\delta_1$ 依赖 $x$"改为"$\delta_1$ 独立于 $x$",即把动态依赖转为静态预设——解除累次的主从关系,使其在数值上退化为二重的对称关系。

## 八、记忆锚点

### 8.1 四条关系结论

1. **二重存在 + 累次存在** $\Rightarrow$ **累次值 $=$ 二重值**(核心引理)
2. **二重存在 ⇏ 累次存在**(反例 $x \sin\frac{1}{y}$)
3. **两累次都存在但不相等** $\Rightarrow$ **二重不存在**(最实用判据)
4. **一个累次存在 + 对应方向一致收敛** $\Rightarrow$ **二重存在**(Moore-Osgood)

### 8.2 四个反例

- $\dfrac{x-y}{x+y}$:累次不等,二重不存在(判据 3)
- $\dfrac{xy}{x^2+y^2}$:累次都为 $0$,斜向路径暴露二重不存在(齐次反例)
- $\dfrac{x^2 y}{x^4 + y^2}$:直线族全为 $0$,抛物线 $y = x^2$ 暴露二重不存在(非齐次反例、非一致收敛反例)
- $x \sin\dfrac{1}{y}$:二重存在,某累次因切片振荡而不存在

### 8.3 三个核心视角

- **几何视角**:二重 $=$ 曲面片整体塌向水平面;累次 $=$ 曲面沿一族切片压成曲线,再压成点。
- **$\delta$ 视角**:累次允许每个 $x$ 专属 $\delta$;二重要求对所有 $(x, y)$ 统一 $\delta$;一致收敛要求专属 $\delta$-族有正下界。
- **独立性视角**:一致收敛 = 阈值对另一变量解耦 = 两变量从主从关系退化为独立对称关系 = 贯穿整个分析学的"一致 X"的共通结构。
