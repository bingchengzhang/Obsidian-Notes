- **动作**：Push A, Push B, Push C。
- **物理结果**：A 在最底下，B 在中间，C 在栈顶。

## 2. 第二阶段：倾倒过程中的“空间扭转”
当 Dequeue 发生且 `s2` 为空时，触发搬运：

1. 从 `s1` 弹出 C $\rightarrow$ 压入 `s2`。
2. 从 `s1` 弹出 B $\rightarrow$ 压入 `s2`。
3. 从 `s1` 弹出 A $\rightarrow$ 压入 `s2`。

## 3. 第三阶段：s2 顶端的“真相大白”
现在看 `s2` 内部的物理排布：

- **栈底**：C
- **中间**：B
- **栈顶**：**A**
**重点来了：** 那个在 `s1` 里最憋屈、被压在最底下的 A，经过这一番“乾坤大挪移”，现在赫然站在了 `s2` 的栈顶（Top）。
所以你说的没错：**s2 的栈顶元素，绝对就是当初第一个进入 s1 的那个元素。**

## 4. 那么，“Then pop from s2” 这一步在干嘛？
这一步的意义在于**“完成交付”**：

- **结果**：A 被弹出来了，交给用户。
- **连锁反应**：A 消失后，原本排在它后面的 B 顺理成章地变成了 `s2` 的新栈顶。下一次你想出队时，B 已经在那里等着你了。
