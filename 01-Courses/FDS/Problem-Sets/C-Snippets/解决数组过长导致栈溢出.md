结论先行：面对 $10^6$ 这种级别的上限，你绝对不能在 `main` 函数内部定义数组。如果 $N = 10^6$，两个 `int` 栈加起来就是 **8MB**。在 Windows 环境下，普通的**系统栈（System Stack）**默认只有 1MB 左右，你强行塞进去会导致程序还没运行就直接崩溃（Stack Overflow）。
解决这个问题有两个硬核方案，分别对应“懒人写法”和“专业写法”：

## 1. 方案 A：利用全局静态区（最简单）
在 C 语言中，定义在 `main` 函数之外的变量不占用系统栈，而是占用**全局/静态存储区**。这个区域的大小限制通常远高于 1MB，足以容纳 8MB 的数据。
**操作方法：** 保持你现在的结构，确保 `struct stack s1, s2;` 定义在 `main` 函数的最外面。

```c
#include <stdio.h>

#define MAX_N 1000005 // 略大于 10^6

struct stack {
    int element[MAX_N];
    int top;
};

// 必须放在这里！全局区可以支撑 10^6 级别的数组
struct stack s1, s2;

int main() {
    // 逻辑代码...
}

```

## 2. 方案 B：利用堆内存（Heap）动态分配（最专业）
如果你追求工程上的严谨，或者担心全局变量污染，你应该使用 `malloc` 从**堆（Heap）**中申请空间。堆的大小通常只受限于你电脑物理内存的大小，跑几百 MB 都没问题。
**重构后的专业版代码：**

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int *element; // 改成指针
    int top;
} Stack;

int main() {
    int N;
    if (scanf("%d", &N) != 1) return 0;

    Stack s1, s2;
    // 从堆内存申请空间：N * 4 字节
    s1.element = (int *)malloc(N * sizeof(int));
    s2.element = (int *)malloc(N * sizeof(int));
    s1.top = -1;
    s2.top = -1;

    // 检查内存是否申请成功（防御性编程）
    if (s1.element == NULL || s2.element == NULL) return -1;

    char op;
    for (int i = 0; i < N; i++) {
        scanf(" %c", &op);
        if (op == 'I') {
            int val;
            scanf("%d", &val);
            s1.element[++s1.top] = val;
        } else if (op == 'O') {
            if (s2.top == -1) {
                if (s1.top == -1) {
                    printf("ERROR\n");
                    continue;
                }
                while (s1.top > -1) {
                    s2.element[++s2.top] = s1.element[s1.top--];
                }
            }
            printf("%d\n", s2.element[s2.top--]);
        }
    }

    // 程序结束记得释放内存（好习惯）
    free(s1.element);
    free(s2.element);
    return 0;
}

```

## 专家级避坑提示：

1. **调试器的报错**：当你用了 $10^6$ 级别的数组后，调试器依然会报 `<error reading variable...>`。**请无视它。** 这仅仅是调试器不想显示那么多数据，只要程序能跑出正确结果，这个报错就是空气。
2. **输入速度瓶颈**：当 $N$ 达到 $10^6$ 时，`scanf` 和 `printf` 的速度可能会成为瓶颈。如果题目时限很紧，建议在 `printf` 后面用 `\n` 而不是 `endl`（针对 C++ 用户），或者改用更快的 `getchar` / `putchar`。
3. **内存计算**：$10^6 \times 4$ 字节 $\approx 4\text{MB}$。两个栈就是 $8\text{MB}$。如果你的题目限制内存是 $16\text{MB}$，这种双栈写法刚好压线通过；如果限制是 $4\text{MB}$，那你就不能用这种双栈数组法，必须改用更省内存的链表法。
