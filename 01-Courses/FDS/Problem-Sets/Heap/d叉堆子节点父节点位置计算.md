### 1. 孩子节点（Children）的推导
假设当前节点位于位置 $i$：

- **逻辑起点**：在位置 $i$ 之前，有 $i-1$ 个节点 。
- **跨越跨度**：这 $i-1$ 个节点每个都有 $d$ 个孩子 。所以，排在 $i$ 的第一个孩子之前的“孩子辈”节点共有 $(i-1)d$ 个。
- **物理位置**：加上处于最顶端的根节点（1个），$i$ 的第一个孩子的下标就是：$\text{First Child} = (i - 1)d + 2$
- **范围延伸**：既然第一个孩子在 $(i-1)d + 2$，那么最后一个孩子（第 $d$ 个）就在：$\text{Last Child} = \text{First Child} + (d - 1) = (i - 1)d + 2 + d - 1 = id + 1$

---

### 2. 父节点（Parent）的推导（向下取整版）
这是你最关心的部分。我们要从孩子的公式反推回父节点 $i$。
已知 $i$ 的孩子范围是 $[(i-1)d+2, \quad id+1]$。
令某个孩子的下标为 $j$。我们需要找到一个函数 $f(j) = i$。

1. 根据范围：$(i-1)d + 2 \le j \le id + 1$
2. 左右各减 2：$(i-1)d \le j - 2 \le id - 1$
3. 同时除以 $d$：$i-1 \le \frac{j-2}{d} \le i - \frac{1}{d}$
4. **关键步骤**：观察不等式。由于 $i$ 是整数，且 $\frac{j-2}{d}$ 的最大值比 $i$ 稍微小一点（即 $i - \frac{1}{d}$），这意味着：$i - 1 \le \text{某个数} < i$
5. 对这个区间应用**向下取整**：$\lfloor \frac{j-2}{d} \rfloor = i - 1$
6. 最终反出父节点 $i$：$i = \lfloor \frac{j-2}{d} \rfloor + 1$
通过通分，这也可以写成：

$$
i = \lfloor \frac{j + d - 2}{d} \rfloor
$$
