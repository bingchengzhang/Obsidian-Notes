# 出度与入度

## 基本定义

**出度 (out-degree)**：从节点 u 出发的有向边数量，记作 deg⁺(u)。
**入度 (in-degree)**：指向节点 u 的有向边数量，记作 deg⁻(u)。

无向图不区分方向，统称**度数 (degree)**，记作 deg(u)。

## 和边数的关系

有向图：

    所有节点出度之和 = 所有节点入度之和 = 边数 Ne

因为每条有向边恰好贡献一个出度（在起点）和一个入度（在终点）。

无向图：

    所有节点度数之和 = 2 × Ne

因为每条无向边给两个端点各贡献 1 度。

## 在邻接表上的体现

graph[u] 的链表长度 = u 的出度（链表存的都是从 u 出发能到的节点）。

入度无法直接读出，需要遍历全图统计"有多少条边的终点是 u"。
如果频繁需要入度，通常另维护一个 indegree[MAXV] 数组，建图时同步更新：

```c
int indegree[MAXV] = {0};

void addEdge(int u, int v, int w) {
    /* 正常插入邻接表 */
    ...
    indegree[v]++;   /* v 的入度加一 */
}
```

## 特殊节点

- 入度为 0：没有任何边指向它，是"源点"，拓扑排序从这里开始剥离。
- 出度为 0：没有任何出边，是"汇点"，拓扑排序最后剩下它。
- 孤立节点：度数为 0（无向）或出度入度均为 0（有向），与图的其余部分没有任何连接。
